Flashing uses your browser's Web Serial API, which Chrome/Edge only allow on secure (HTTPS) pages or on localhost. If this Ingress page is served over plain HTTP on your LAN, open it via Home Assistant's HTTPS URL, or open ESPectre Hub directly at http://<host>:8099 from the same machine.

Add a device

Devices

Once a device is built and flashed, its card shows live motion state and lets you push a new detection threshold or trigger recalibration — read from Home Assistant, using the entity ids under "HA entity ids" (best-effort guesses; edit them if a device shows as unavailable).

Add a zone

Zones

A zone reports "occupied" when any of its member devices currently detects motion (OR-logic) — the same aggregation TOMMY calls zone/topology mode, kept simple for now.
